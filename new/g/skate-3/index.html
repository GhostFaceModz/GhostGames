About Skate 3 Browser

Skateboarding simulator in browser. Pull off flips, grinds and tricks.

Controls

W / SPush / brakeA / DTurnMouse / right stickFlick tricksSpaceOllieEscMenu

Needs a keyboard and mouse, so it won't play properly on phones or tablets.

Tips

  • Learn the basic moves before going for combos.
  • Fullscreen gives the best feel and frame rate.

Game not loading?

  • Reload the game: a fresh start fixes most stuck loading screens.
  • Chrome or Edge on PC work best. Turn off ad blockers and privacy shields for this site.
  • Click inside the game to give it keyboard and mouse focus. Press Esc to release the mouse.
